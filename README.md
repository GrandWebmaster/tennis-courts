# Свободные корты

Страница с расписанием свободных кортов центра «Проспект» в Рыбинске: три
закрытых теннисных с покрытием хард и корт для падела. Видно, что свободно
в ближайшие десять дней, клик по корту ведёт на бронь.

Открывается тут: https://grandwebmaster.github.io/tennis-courts/

## Как устроено

Сайт статический и во время просмотра никуда не ходит: страница читает только
свой `data.json`, лежащий рядом. Данные в этот файл кладёт GitHub Action.

```
build/config.json   источники, корты, услуги, тарифные окна, праздники
build/fetch.py      собирает data.json из открытого API онлайн-записи
data.json           результат сборки, обновляется автоматически
index.html          страница
assets/             стили и рендер сетки
```

Раз в два часа workflow запускает `build/fetch.py`, тот опрашивает десять дней
и переписывает `data.json`. Если свободное время не изменилось, коммита нет —
незачем плодить пустую историю.

Интервал выбран под то, как GitHub на самом деле ведёт себя с расписанием. Просили
каждые пятнадцать минут, по факту проходило три-пять запусков в сутки: на бесплатных
публичных репозиториях `schedule` выполняется по остаточному принципу. Два часа —
честная заявка, которую не приходится пропускать.

## Откуда берутся слоты

Онлайн-запись отдаёт свободное время через открытый ajax-эндпоинт. Запрос без
идентификатора мастера возвращает сразу все корты компании, поэтому на день хватает
одного обращения.

Источников два, и это важно: теннис и падел заведены в сервисе записи разными
компаниями, со своими услугами и своим прайсом. Оба описаны в `build/config.json`
в списке `sources`, и собираются они по-разному.

С теннисом просто. Тарифное окно услуги на выдачу слотов не влияет, а длительности
выводятся из получасовок: час свободен там, где свободны две смежные, полтора часа —
три. Сверили с ответами сервиса для часовой и полуторачасовой аренды, совпадает
точно. Хватает одного запроса на день, в конфиге это стратегия `derive`.

С паделом так нельзя. Его корт живёт на часовой сетке, а получасовые старты сервис
добавляет по краям чужих броней, чтобы не простаивали остатки: если кто-то взял
с 14:00 на полтора часа, следующим предложат 15:30, а не 16:00. Из получасового
списка это не вывести, проверка на пяти днях не совпала ни разу. Поэтому каждая
длительность запрашивается отдельно, стратегия `per_duration`.

Полтора часа у падела отдельной услугой не заведены, их набирают часом плюс
получасом. Параметр `service_id[]` принимает несколько услуг и складывает их
длительности, так что спросить про 90 минут всё равно можно, а цена получается
суммой двух услуг.

Итого сорок запросов на сборку, они уходят параллельно за несколько секунд.

Цена зависит от корта, времени и дня недели: под каждое тарифное окно заведена
отдельная услуга. Окна перечислены в `build/config.json`, из них берётся и цена
в подсказке, и ссылка на бронь нужной услуги. Полуторачасовой теннисной аренды
в будни на 07:00–08:00 и после 21:00 в прайсе нет, такие слоты идут без цены.

Ссылка умеет подставить только одну услугу: две через запятую или повтором параметра
сервис записи не принимает. Для полутора часов на паделе она подставляет час,
а подтверждение перед переходом просит добрать вторую услугу руками.

Ещё сервис записи иногда подсовывает «ближайшее доступное время» от текущего момента,
старт вроде 15:05, который на получасовую ось не ложится. Такие слоты сборщик
отбрасывает и пишет об этом в лог: иначе `data.json` говорил бы одно, а страница
показывала другое.

## Запустить у себя

```bash
python3 build/fetch.py
python3 -m http.server 8000
```

Зависимостей нет, только стандартная библиотека Python 3.

## Оговорки

Данные не мгновенные. Между обновлениями проходит пара часов, иногда больше, и за
это время слот могли занять. Возраст расписания показан над таблицей, а если он
перевалит за пять часов, появится предупреждение: значит обновление не отработало
вовсе, а не просто ждёт своей очереди.

Праздники перечислены датами в `build/config.json` и правятся руками раз в год:
переносы выходных утверждаются постановлением, из календаря их не вычислить.

Расписание неофициальное. Итоговое время и цену подтверждает центр при записи.
